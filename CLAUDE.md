# Claude Code Instructions

## Project Overview

Replication repository for "Who Owns the Floodplain?" published in Environment and Planning B.

## Directory Structure

- `data/` - Processed datasets for replication
- `code/` - Analysis scripts (Python)
- `figures/` - Output figures for publication
- `docs/` - Methodology and data documentation

## Guidelines

- Keep data files well-documented with clear variable names
- Analysis scripts should be reproducible
- Figures should be publication-ready (PNG and PDF formats)
