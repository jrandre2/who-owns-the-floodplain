# Claude Code Instructions

## Project Overview

This repository contains the manuscript "Who Owns the Floodplain?" examining property ownership structure and flood exposure in Douglas County, Nebraska.

## Key Information

- **Manuscript ID**: EPB-2025-0878
- **Journal**: Environment and Planning B: Urban Analytics and City Science
- **Status**: Major Revisions (due March 16, 2026)

## Directory Conventions

- `manuscript/` - Primary submission documents (Word format)
- `revision/` - All revision-related materials including reviewer responses
- `figures/` - Publication-ready figures
- `supplementary/` - Supplementary materials for the journal
- `docs/` - Internal documentation and methodology notes
- `archive/` - Historical drafts (do not modify)

## Important Files

- `manuscript/Who_Owns_the_Floodplain_20250909.docx` - Original submission
- `revision/Response_to_Reviewers.md` - Consolidated reviewer response
- `revision/Tables_Main_Revised_20251216.docx` - Revised analysis tables

## Guidelines

- DO NOT modify files in `archive/`
- When editing manuscript, create new versions with date stamps
- Keep reviewer response documents in sync (md, docx, pdf formats)
- Figures should be saved in both PNG and PDF formats where applicable
